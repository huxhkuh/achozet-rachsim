# אחוזת רכסים

אתר תדמית סטטי בעברית: יזמות בוטיק, השבחה ושיווק נכסים.

## הפעלה ופרסום

פותחים את `index.html` בדפדפן, או מעלים את קובץ ה־HTML ואת תיקיית `assets` לאירוח סטטי. אין צורך בהתקנה או בתהליך בנייה. כל הנתיבים יחסיים.

האתר כולל תמונות מותאמות למסכים שונים, פונטים מקומיים, חלונות פרויקטים ומעבר בגלילה משרטוט להדמיה. בהגדרת הפחתת תנועה מוצגת הדמיה קבועה.

הטופס מחובר ל־Formspree ודורש אינטרנט. ניהול יעד ההתראות מתבצע בחשבון השירות; מזהה הטופס הציבורי אינו מפתח סודי.

## לפני השקה בדומיין

יש לעדכן את `og:image` ו־`twitter:image` לכתובת HTTPS מוחלטת של `assets/social-preview.jpg` בדומיין הסופי, ולהוסיף canonical ו־og:url. לאחר הפרסום יש לבדוק תצוגת שיתוף וקבלת פנייה בפועל.

הדמיות ושרטוטים להמחשה בלבד. יש לאמת נתוני פרויקטים וזמינות לפני פרסום עסקי.

רישיונות הפונטים נמצאים בתיקיית `assets`. חומרי המקור העסקיים אינם כלולים במאגר.
